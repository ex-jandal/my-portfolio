## Obsidian

[Obsidian](https://obsidian.md/) is my knowledge management system — a local-first, markdown-based note-taking app that turns plain text files into a connected network of thoughts.

### My Workflow

- **Dataview plugin**: Query notes like a database — project trackers, daily logs, resource lists
- **PARA method**: Organize notes into Projects, Areas, Resources, and Archives
- **Templates**: 7 note templates with YAML frontmatter for automated metadata
- **Dashboard**: Home page with 6 Dataview queries — Inbox, Projects, Daily Logs, Writeups, CheatSheets, Study Guides
- **Capture**: Custom `cap` function in fish shell for quick inbox capture

### Why It Works for Me

Obsidian's local-first philosophy and plain-text storage align with my preference for tools that respect user freedom and data ownership. Combined with the PARA method, it keeps my learning organized without locking me into a proprietary format.
