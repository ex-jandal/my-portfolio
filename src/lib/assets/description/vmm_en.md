## VMM (Virtual Machine Manager)

I use VMM (virt-manager) for virtualization — running isolated Linux environments for development, experimentation, and security testing.

### What I Run

- **Kali Linux**: Security testing and CTF practice
- **Parrot OS**: Additional security-focused environment
- **Various distros**: Testing and experimentation

### Why Virtualization Matters

Virtual machines provide safe, isolated environments for:
- Testing system-level code without risking the host
- Experimenting with different Linux distributions
- Building a lab environment for cybersecurity practice
- Learning kernel and OS concepts in a controlled setting

VMM/QEMU/KVM gives me near-native performance with the flexibility of full system isolation — essential for hands-on systems learning.
