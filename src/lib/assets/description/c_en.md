## C Programming Language

C is the lingua franca of systems programming — the language that built Unix, Linux, and most operating systems. It gives you direct control over memory, minimal abstraction, and a deep understanding of how computers actually work.

### Why C Matters

- **Systems programming**: OS kernels, drivers, embedded systems
- **Memory management**: Manual allocation with `malloc`/`free`, pointers, and pointer arithmetic
- **Performance**: Zero-cost abstractions, predictable execution
- **Portability**: C compilers exist for virtually every platform
